# 本版合并说明

本轮只处理已经取得的材料，不继续重试视频下载，也不把未读内容猜补成结论。

## 输入与权威入口

输入为原 v0.1.0 仓库、最初资源目录、网页/节目入口补读附件，以及两段同场短片和替代音源笔记。
这些输入及归档哈希见 [inputs.json](../research/inputs.json)，旧文档见 [history](../research/history/README.md)。

当前规则的权威入口是 `skills/humanist-frontend/references/01–05`；当前来源的权威入口是 `research/sources.json`；版本在 `release.json`。
主规范、来源审计、覆盖统计和独立 Skill 来源副本均有生成器，减少互相矛盾的手工副本。

## 已合入，不再仅作为附件的部分

K9 的自动标题启发转成 CMP-04；K10-R1 的输入建议转成 CMP-05；K8 的跳过入口转成 AGT-04；K11 的历史付费表达转成 COPY-01。
A7 两段短片转成 CTX-06 的任务样例方法；证据获取中的边界整理为 SRC-01。
工程上的失败恢复、竞态、取消和交易透明要求属于本项目原创迁移，不冒称已在原产品验证。
规则与评估场景映射见 [rule_traceability.json](../research/rule_traceability.json)。

## 保留的缺口

A3 和 A7 两期完整访谈仍未取得全文；A7 只读了两段主持人发布的短片可见转录，未音轨复核。
K6、K7、K10 原帖正文仍未取得。K10 的同作者汇编另列条目，不更改原帖获取状态。
案例图片/动效的核验没有因为读到正文而自动完成。已有音频路由不等于已下载的媒体资产。

这些限制只影响可作证据的范围，不妨碍将已读内容形成当前规范。新版不会因此强制用户额外安装转录插件或每次设计重新研究。

## 打包范围

完整包包括规范、完整 Skill、来源/历史笔记、模板、脚本、测试、评估设计与发布记录。
不含第三方文章全文、原始字幕、完整音视频、品牌字体/Logo，也没有混入其他原型项目的截图。
包中保留的是原创摘要与出处，并非离线镜像所有外部网页。
